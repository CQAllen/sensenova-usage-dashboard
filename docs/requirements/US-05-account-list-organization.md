# US-05 账号列表排序、筛选、搜索与偏好记忆

| 项目 | 内容 |
|---|---|
| Story ID | US-05 |
| 优先级 | P1 |
| 依赖 | 无 |
| 状态 | 草案 |
| 关联 | [需求池总览](README.md) · US-04 |

---

## 1. 背景与问题

账号总览目前按配置顺序展示全部账号，没有排序、筛选或搜索。账号数量达到 5 个以上时，用户需要逐行扫描才能找到「哪个快满了」「哪个不可用」；账号更多时，表格长度和认知负担会继续增加。

本 Story 提供轻量的列表组织能力，并记住用户偏好，避免每次打开都重新设置。

---

## 2. 用户故事

> 作为持有多个账号的用户，我希望按剩余额度或可用状态排序、只看异常账号、按名称搜索，这样我能在几秒内找到需要处理的账号。

**完成条件**：用户可以在账号总览对列表排序、筛选、搜索，关闭应用再打开后偏好仍然保留。

---

## 3. 范围

### P0

- 按账号名、状态、5h 剩余率、7d 剩余率、下次重置时间排序。
- 按状态筛选：全部 / 可用 / 降级 / 不可用 / 查询异常。
- 按账号名搜索，大小写不敏感。
- 显示当前结果数量与清除筛选入口。
- 偏好持久化。

### P1

- 账号分组 / 标签。
- 置顶常用账号。
- 保存多个筛选视图。
- 账号明细页同步排序与筛选。

### 不做

- 跨账号合并同名账号。
- 自定义列显隐（后续再评估）。
- 拖拽排序并写回平台配置。

---

## 4. 核心流程

```
账号总览渲染
  → 读取偏好（排序、筛选、搜索词）
  → 按偏好处理账号集合
  → 渲染表格与结果计数
  → 用户修改排序 / 筛选 / 搜索
  → 立即重排，不重新请求数据
  → 偏好持久化
```

---

## 5. 功能需求

### US05-FR1 排序

**触发**：用户点击表头，或从排序下拉中选择。

**规则**：

1. 排序维度：

| 维度 | 默认方向 | 排序依据 |
|---|---|---|
| 账号名 | 升序 | 自然顺序，大小写不敏感 |
| 可用性 | 可用 → 降级 → 不可用 → 查询异常 | 同状态内按账号名升序 |
| 5h 剩余率 | 升序（少 → 多） | 通用积分池；无数据置底 |
| 7d 剩余率 | 升序 | 通用积分池；无数据置底 |
| 下次重置 | 升序（早 → 晚） | 优先 5h 重置时间；无数据置底 |
| 默认顺序 | - | 沿用账号配置顺序 |

2. 再次点击同一维度切换升 / 降序。
3. 查询异常账号始终排在正常账号之后，除非用户选择的排序维度明确要求（如按账号名排序）。
4. 无数据账号排在最后，并在该列显示 `-`。
5. 排序结果稳定：相同值按账号名升序。

### US05-FR2 筛选

**规则**：

1. 筛选项：全部（默认）、可用、降级、不可用、查询异常。
2. 单选，不叠加。
3. 筛选后若结果为空，显示「当前筛选下没有账号」+「查看全部」。
4. 筛选只影响总览展示，不影响明细页、账号管理与数据刷新。
5. 账号状态在刷新后变化时，按当前筛选重新计算；账号移出筛选范围时直接消失，不做动画提示。

### US05-FR3 搜索

**规则**：

1. 输入即搜索，不做回车确认。
2. 匹配账号名，大小写不敏感，支持部分匹配。
3. 搜索与筛选同时生效，取交集。
4. 搜索词去除首尾空格；空字符串视为无搜索。
5. 无结果时显示：「没有匹配「{关键词}」的账号」+「清除搜索」。

### US05-FR4 结果计数与重置

**规则**：

1. 表格上方显示「显示 {N} / {总数} 个账号」。
2. 存在任一筛选条件（排序不算）时，显示「清除筛选」。
3. 点击「清除筛选」恢复：全部状态、空搜索词、默认顺序；不重置用户保存的排序偏好 `[Assumption, TBD]`。

### US05-FR5 偏好持久化

**规则**：

1. 持久化内容：排序维度、排序方向、筛选状态、搜索词。
2. 搜索词是否持久化 `[Assumption, TBD]`；默认建议持久化，便于下次继续查找。
3. 偏好非法或缺失时回退默认值，不阻塞渲染。
4. 偏好变化后立即保存；保存失败不影响当前会话使用，下次启动回退默认。
5. 偏好属于本机设置，不参与账号配置合并。

### US05-FR6 空态

| 场景 | 展示 |
|---|---|
| 无账号 | 沿用现有「还没有配置任何账号」提示 |
| 筛选 / 搜索无结果 | 针对性空态 + 清除入口 |
| 全部账号查询异常 | 保留表格行，显示异常原因；筛选「查询异常」可集中查看 |

## 6. 界面与交互

```
账号总览                                        显示 6 / 12 个账号
[全部 | 可用 | 降级 | 不可用 | 查询异常]   [搜索账号…]  [清除筛选]

账号 ▲        通用5h   通用7d   活动固定积分   Flash-Lite 5h  ...
```

- 表头可点击排序，显示升 / 降箭头。
- 筛选采用分段按钮，不使用下拉，减少一次点击。
- 搜索框宽度固定，输入时表格即时更新，不闪烁。
- 在窄窗口下，工具栏允许换行，不遮挡表格。

---

## 7. 数据与状态

| 对象 | 字段 | 说明 |
|---|---|---|
| 列表偏好 | 排序维度、方向、筛选状态、搜索词 | 持久化到本机设置 |
| 渲染状态 | 当前可见账号、结果计数 | 内存态 |

**一致性要求**：筛选、搜索、排序基于同一份最近查询结果，不额外请求后端。

---

## 8. 异常与边界

| 场景 | 行为 |
|---|---|
| 偏好含未知排序字段 | 回退默认顺序 |
| 搜索包含特殊字符 | 按纯文本匹配，不做正则解释 |
| 刷新期间用户修改筛选 | 立即生效，刷新完成后保持当前偏好 |
| 账号在筛选状态下状态变化 | 按新状态重新归组，可能从列表消失 |
| 偏好保存失败 | 当前会话继续生效，下次启动回退默认 |
| 账号名为空 | 归入「未知」，可按异常状态筛选 |

---

## 9. 对现有功能的影响

- **账号总览**：表格渲染前增加处理管线；导出（US-08）默认导出全部账号，还是当前筛选结果需明确 `[TBD]`。
- **账号明细**：本期不跟随筛选，后续 P1 统一。
- **设置存储**：新增列表偏好字段，需兼容旧配置。
- **性能**：账号数量在数十个以内时前端处理即可。
