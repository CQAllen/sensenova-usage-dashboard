# US-08 用量数据导出

| 项目 | 内容 |
|---|---|
| Story ID | US-08 |
| 优先级 | P1 |
| 依赖 | US-03（按时间范围导出需要历史数据；当前快照导出不依赖） |
| 状态 | 草案 |
| 关联 | [需求池总览](README.md) · US-03 |

---

## 1. 背景与问题

用量数据目前只能在界面查看，无法用于团队额度分配、费用对账或问题复盘。用户如果需要记录，只能手工截图或抄写。

本 Story 提供本地导出能力，把当前快照或历史区间导出为结构化文件，且绝不包含任何凭据。

---

## 2. 用户故事

> 作为需要向团队说明额度使用情况的用户，我希望把当前用量或一段时间的用量导出为表格文件，这样可以直接用于对账和汇报，不必手工整理。

**完成条件**：用户可以选择导出范围，保存为可被 Excel 正常打开的 CSV，内容与界面口径一致。

---

## 3. 范围

### P0

- 导出当前快照（所有账号、所有积分池、两个窗口）。
- 导出指定时间范围的历史（依赖 US-03）。
- CSV 格式，UTF-8 带 BOM，Excel 可直接打开。
- 系统保存对话框选择路径与文件名。
- 导出成功提示文件路径，可打开所在目录。
- 空数据、取消、写入失败处理。

### P1

- JSON 导出（便于二次处理）。
- 仅导出当前筛选结果（依赖 US-05）。
- 定时自动导出。
- Excel 多工作表（汇总 + 明细）。

### 不做

- 导出 API Key、密码、JWT 或任何凭据。
- 上传到云端或直接发送邮件。
- 平台侧账单数据导出（平台未提供）。

---

## 4. 核心流程

```
用户点击「导出」
  → 选择范围：当前快照 / 历史区间
  → 若选历史：选择开始与结束时间（默认最近 7 天）
  → 选择保存位置
  → 生成 CSV
  → 保存成功 → 提示路径
  → 用户取消 / 无数据 / 写入失败 → 对应提示
```

---

## 5. 功能需求

### US08-FR1 导出入口与范围

**规则**：

1. 账号总览页提供「导出」按钮；账号明细页可选提供同一入口 `[Assumption, TBD]`。
2. 范围选项：

| 范围 | 数据来源 | 默认 |
|---|---|---|
| 当前快照 | 最近一次成功查询结果 | 是 |
| 历史区间 | US-03 的历史快照 | 否 |

3. 选择历史区间时，提供开始时间与结束时间：
   - 默认最近 7 天。
   - 结束时间不得早于开始时间。
   - 范围不得超过 90 天（历史保留上限）。
4. 若 US-03 未上线或历史为空，历史范围选项禁用并提示。

### US08-FR2 CSV 内容

**导出粒度**：一行 = 一个账号 × 一个积分池 × 一个窗口。

**列定义**：

| 列 | 内容 | 示例 |
|---|---|---|
| 时间 | 快照时间，本地时区 `YYYY-MM-DD HH:MM:SS` | 2026-10-21 14:32:00 |
| 账号 | 账号名 | account_03 |
| 套餐 | 当前套餐名，缺失为空 | Free Plan |
| 积分池 | 池名称 | 通用积分池 |
| 池类型 | 通用 / 专属 | 通用 |
| 窗口 | 5h / 7d | 5h |
| 上限 | 数值，不带千分位 | 10000 |
| 已用 | 数值，不带千分位 | 6820 |
| 剩余 | 数值，不带千分位 | 3180 |
| 使用率 | 百分比数值，保留一位小数 | 68.2 |
| 重置时间 | 本地时区 `YYYY-MM-DD HH:MM` | 2026-10-21 16:47 |
| 活动固定积分 | 数值 | 0 |
| 账号可用性 | 可用 / 降级 / 不可用 / 查询异常 | 可用 |

**规则**：

1. 当前快照导出时，「时间」为最近一次查询时间，每个账号使用同一时间。
2. 历史导出时，按时间升序排列；同一时间点内按账号、池、窗口排序。
3. 查询异常的账号仍导出，可用性列标记为「查询异常」，用量列为空。
4. 上限为 0 或无数据的字段留空，不填 0。
5. 数值列使用原始数值，不加千分位，保证 Excel 可计算。
6. 不输出账号密码、JWT、API Key、本地路径、端口等敏感信息。

### US08-FR3 文件格式与命名

**规则**：

1. 编码 UTF-8 带 BOM，换行使用 CRLF，确保 Windows Excel 正常显示中文。
2. 文件名默认：`SenseNova用量_{YYYYMMDD_HHMM}.csv`。
3. 用户可通过系统保存对话框修改文件名与位置。
4. 覆盖已有文件前，由系统保存对话框负责确认。
5. 导出文件为一次性快照，不与应用后续状态联动。

### US08-FR4 保存与反馈

**规则**：

1. 使用原生保存对话框，默认目录为上次导出目录；无记录时使用系统默认文档目录。
2. 保存成功：提示「已导出 N 行到 {文件名}」，提供「打开所在文件夹」。
3. 用户取消保存：不提示错误，保持页面原状。
4. 写入失败：提示失败原因（脱敏），保留内存数据，允许重试。
5. 导出期间按钮进入 busy 态，避免重复点击。

### US08-FR5 空数据与边界

| 场景 | 行为 |
|---|---|
| 未配置账号 | 禁用导出按钮，提示先配置账号 |
| 最近查询失败且无历史 | 提示「暂无可导出的数据」 |
| 历史区间内无数据 | 提示「所选时间范围内没有数据」 |
| 只导出当前快照但有账号异常 | 正常导出，异常行标注 |
| 历史数据部分损坏 | 导出可读取部分，提示「部分历史数据无法读取」 |

## 6. 界面与交互

```
账号总览                                          [导出]
```

点击后弹窗：

```
导出用量数据
  范围  (•) 当前快照   ( ) 历史区间
  时间  [2026-10-14] 至 [2026-10-21]   （仅历史区间可用）
  格式  CSV
        [取消]  [导出]
```

- 范围切换时，时间选择器相应启用 / 禁用。
- 导出成功后 toast + 可点击「打开所在文件夹」。
- 不使用浏览器下载，统一走原生保存对话框，行为与图片下载一致。

---

## 7. 数据与状态

| 对象 | 字段 | 说明 |
|---|---|---|
| 导出设置 | 上次导出目录 | 持久化，不含敏感信息 |
| 导出任务 | 范围、开始/结束时间、行数 | 内存态 |
| 导出内容 | 见 US08-FR2 列定义 | 一次性生成，不落盘缓存 |

---

## 8. 异常与边界

| 场景 | 行为 |
|---|---|
| 用户取消保存对话框 | 静默返回 |
| 目录无写入权限 | 提示更换目录或检查权限 |
| 文件被占用 | 提示关闭占用程序后重试 |
| 历史数据量过大 | 导出全部匹配行，提示行数；生成过程不阻塞界面 |
| 时间范围非法 | 就地提示，不发起导出 |
| 导出过程中查询刷新 | 当前快照导出使用点击时的数据，不受刷新影响 |

---

## 9. 对现有功能的影响

- **账号总览**：新增导出入口与弹窗。
- **历史数据**：US-03 需提供按时间范围读取的能力。
- **原生保存**：复用现有 pywebview 保存桥接能力，扩展为文本文件。
- **隐私**：导出内容必须经过字段白名单，禁止直接序列化内部对象。
