# US-07 图像生成工作流增强

| 项目 | 内容 |
|---|---|
| Story ID | US-07 |
| 优先级 | P1 |
| 依赖 | 无 |
| 状态 | 草案 |
| 关联 | [需求池总览](README.md) |

---

## 1. 背景与问题

当前图像生成页支持单次文生图 / 图生图，但每次都要重新选择模型、尺寸、提示词扩展与水印，生成后还要手动下载并选择目录。批量出图只能反复点击，且「取消」只中断了浏览器请求，后端仍可能继续调用付费接口。

本 Story 把图像生成从“单次表单”提升为可重复使用的工作流：保存常用参数、一次生成多张、自动落盘、真正取消。

---

## 2. 用户故事

> 作为经常批量生成配图的用户，我希望保存常用的模型与尺寸组合、一次生成多张并自动保存到指定目录，同时能在取消后停止后续生成，这样不必重复配置和逐张下载。

**完成条件**：用户可以一键套用参数预设，一次发起多张生成，结果自动保存到指定目录；取消后不再发起后续请求。

---

## 3. 范围

### P0

- 参数预设：保存 / 套用 / 删除常用配置。
- 批量生成：一次 1–4 张，串行执行。
- 自动保存目录：可配置，生成成功后自动保存。
- 服务端取消：取消后不再发起后续请求，并尽力终止当前请求。
- 批量进度与逐张结果状态。

### P1

- 提示词历史与收藏。
- 风格模板。
- 生成结果对比视图。
- 批量任务失败后一键重试。

### 不做

- 并发生成（避免触发限流与额度瞬时消耗）。
- 云端任务队列。
- 自动上传参考图到第三方存储。

---

## 4. 核心流程

```
选择账号 → 选择预设（可选）→ 配置参数 → 选择数量
  → 点击生成
  → 按数量串行发起
      → 每张成功：展示结果、推入历史、按设置自动保存
      → 每张失败：记录失败原因，继续下一张（除非用户取消）
  → 全部完成：汇总成功 / 失败数量
```

取消路径：用户点击取消 → 标记任务取消 → 不再发起下一张 → 当前请求尽力中断 → 展示已完成的图片与取消说明。

## 5. 功能需求

### US07-FR1 参数预设

**触发**：用户在图像生成页点击「保存为预设」。

**规则**：

1. 预设包含：模式（文生图 / 图生图）、模型、尺寸、自动润色提示词、水印。
2. 不包含：提示词正文、参考图、账号。避免预设携带用户内容或凭据。
3. 预设名称必填，1–20 个字符 `[Assumption, TBD]`，同一用户下不可重名；重名时提示并拒绝保存。
4. 最多保存 10 个预设 `[Assumption, TBD]`。
5. 套用预设只覆盖预设内包含的字段，不修改提示词与参考图。
6. 删除预设需二次确认；删除后不影响已生成结果。
7. 预设持久化到本机设置，不含任何凭据。

### US07-FR2 批量生成

**触发**：用户在生成区选择数量（1–4）后点击生成。

**规则**：

1. 批量任务串行执行，同一时刻仅一个图像请求在途。
2. 每张结果独立：
   - 成功：展示缩略图、推入本次会话历史、按 US07-FR4 自动保存。
   - 失败：记录失败原因（脱敏），继续下一张。
3. 批量期间显示「第 x / N 张」进度与当前状态。
4. 批量按钮在任务进行中禁用；用户可以取消。
5. 额度不足、鉴权失败等**不可恢复错误**出现时，停止后续生成，并提示原因。
6. 网络超时等可能恢复的错误，按现有重试策略处理；本 Story 不新增自动重试次数。
7. 批量结果全部保留在历史中，直到用户移除或应用退出。

### US07-FR3 服务端取消

**触发**：用户在生成中点击「取消」。

**规则**：

1. 立即将任务标记为「已取消」，前端停止等待并展示当前已完成结果。
2. 后端收到取消标记后：
   - 不再发起批量中的后续请求。
   - 对当前在途请求，尽力中断连接；若平台仍完成生成并计费，需在界面提示「当前请求可能已经产生费用」。
3. 取消后按钮恢复，可重新发起新任务。
4. 取消不得产生半写入的下载缓存或损坏的历史记录。
5. 取消操作不撤销已经生成并保存的图片。

### US07-FR4 自动保存

**触发**：生成成功，且用户已开启「自动保存到目录」。

**规则**：

1. 用户首次开启时选择目录；目录不存在或无写入权限时不允许开启，并提示原因。
2. 文件名规则：`sensenova_{YYYYMMDD_HHMMSS}_{序号}.{格式}`，序号在同一秒内递增。
3. 同目录存在同名文件时自动追加 `_1`、`_2`，不覆盖。
4. 保存成功：结果卡片显示「已保存」与文件名；保存失败：保留内存结果，提示失败原因，仍可手动下载。
5. 自动保存不阻塞下一张生成；保存失败不影响任务继续。
6. 用户可随时关闭自动保存；已保存文件不回滚。
7. 默认关闭 `[Assumption, TBD]`。

### US07-FR5 批量结果与历史

**规则**：

1. 本次会话历史按生成顺序展示，批量任务中的每张图独立一项。
2. 历史项标记来源：文生图 / 图生图、模型、尺寸、是否自动保存。
3. 历史最多保留 20 项，超出移除最旧；移除仅影响界面，不删除已保存文件。
4. 批量失败项是否进入历史：不进入图片历史，但在任务汇总中保留失败原因 `[Assumption, TBD]`。

### US07-FR6 任务汇总

**规则**：

1. 批量结束后展示：「成功 N 张，失败 M 张，已取消 K 张」。
2. 存在失败时，列出每张的失败原因（最多 3 条，超出折叠）。
3. 汇总信息保留到用户发起下一次生成或离开页面。

## 6. 界面与交互

```
模式 [图片生成 | 图片编辑]     预设 [日常配图 ▾] [保存预设] [管理]
模型 [U1.5 Fast ▾]    尺寸 [2048×2048 ▾]    数量 [1 ▾]
[ ] 自动润色提示词   [ ] 水印
[ ] 自动保存到目录   D:\images\sensenova    [选择目录]
提示词 [........................................................]
[生成图像] [取消]
进度：第 2 / 4 张 · 正在生成…
```

- 数量选择仅提供 1–4，不使用自由输入。
- 预设管理使用轻量弹窗，列出预设名称与删除按钮。
- 批量进行中显示逐张缩略图占位，完成后填充。
- 自动保存开关旁显示当前目录；未选择目录时开关不可开启。

## 7. 数据与状态

| 对象 | 字段 | 说明 |
|---|---|---|
| 参数预设 | 名称、模式、模型、尺寸、润色开关、水印开关 | 持久化，本机，无凭据 |
| 自动保存设置 | 开关、目录 | 持久化 |
| 批量任务 | 任务 ID、总数、已完成、成功数、失败数、取消状态 | 内存态 |
| 单张结果 | 序号、状态、图片引用、保存路径、失败原因 | 内存态 + 已保存文件 |

---

## 8. 异常与边界

| 场景 | 行为 |
|---|---|
| 额度不足 | 停止批量，提示剩余额度与重置时间（若可得） |
| 鉴权失败 | 停止批量，引导检查账号 Key |
| 单张超时 | 记录失败，继续下一张 |
| 取消时当前请求已提交 | 提示可能已产生费用 |
| 自动保存目录被移除 | 保存失败提示，结果保留在内存，可手动下载 |
| 文件名冲突 | 自动追加序号，不覆盖 |
| 参考图超过限制 | 沿用现有前端校验与提示 |
| 预设数量达到上限 | 禁止保存并提示删除旧预设 |

---

## 9. 对现有功能的影响

- **图像生成页**：新增预设、数量、自动保存、进度与任务汇总。
- **生成接口**：需支持任务级取消标记；批量由前端串行发起或后端统一编排，需开发评审确定。
- **下载缓存**：自动保存不得绕过现有缓存与下载逻辑；缓存淘汰规则不变。
- **频控**：批量不得绕过按账号的出图限流；串行天然满足最小间隔。
- **隐私**：预设与历史不包含账号密码、JWT、API Key。
