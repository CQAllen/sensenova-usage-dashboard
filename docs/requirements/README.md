# SenseNova 用量查询 · 需求池

> 文档版本：v0.1（草案）  
> 更新日期：2026-10-21  
> 适用范围：SenseNova 用量查询桌面应用（Windows / macOS）
>
> 说明：本需求池按 Story 组织。每份 Story 文档描述**产品行为与业务规则**，不绑定具体实现方案；开发实现时以本文档的触发条件、计算规则、状态与异常处理为准。

---

## 1. 产品定位

面向同时持有多个 SenseNova 账号的用户，提供「不登录平台就能持续掌握各账号积分池余量」的本地桌面工具。产品的核心不是展示数字，而是让用户在额度耗尽前得到足够早的信号，并能快速决定用哪个账号。

**主要用户**：个人开发者 / 小团队成员，持有 2–10 个 SenseNova 账号，日常通过 API Key 调用模型与图像生成。

**核心任务**：打开工具（或不打开）即可知道——现在哪个账号可用、还能用多久、是否即将耗尽。

## 2. 现状基线（已确认）

以下能力已上线，是本需求池的起点：

| 能力 | 现状 |
|---|---|
| 用量查询 | 每 5 分钟自动刷新（60–3600 秒可调），展示通用积分池与 Flash-Lite 专属池的 5h / 7d 用量 |
| 账号可用性 | 按积分池额度分为「可用 / 降级 / 不可用」，在账号总览展示 |
| 账号管理 | 账号密码登录、JWT 自动刷新、API Key 查看/复制 |
| 图像生成 | U1.5 文生图 / 图生图，结果可下载 |
| 安全 | 凭据加密落盘、不回传明文、本地随机端口、来源校验 |
| 更新 | 启动时检查 GitHub Release，可下载并自动替换 |

**当前缺口**：只能在打开窗口时看到数据；没有历史；没有主动告警；关闭窗口即退出进程；账号多时缺少组织手段。

2. **效率提升**：US-04 + US-05 + US-10。

## 4. 全局术语与共享规则

各 Story 文档直接引用本节定义，不重复展开。

### 4.1 积分池与窗口

| 术语 | 定义 |
|---|---|
| 通用积分池 | `pool_type=default` 的积分池，承载大部分模型调用 |
| Flash-Lite 专属积分池 | `pool_type=dedicated` 的积分池，仅用于 Flash-Lite 类模型 |
| 5h 窗口 | 滚动 5 小时额度窗口，`reset_at` 为下次重置时间 |
| 7d 窗口 | 滚动 7 天额度窗口，`reset_at_7d` 为下次重置时间 |
| 使用率 | `已用 / 上限 × 100%`，保留一位小数；上限为 0 时视为无数据 |
| 活动固定积分 | `grant_balance`，积分池耗尽后可兜底的固定积分 |

### 4.2 账号可用性（沿用现有定义）

| 状态 | 判定 |
|---|---|
| 可用 | 通用积分池 5h 与 7d 均未满；或已满但活动固定积分 > 0 |
| 降级 | 通用池已耗尽，但 Flash-Lite 专属池 5h 与 7d 均未满 |
| 不可用 | 通用池与专属池均耗尽，或无积分池数据 |
| 查询异常 | 该账号本次查询失败（登录失败、网络失败、权限不足等），不参与可用性统计 |

### 4.3 展示规范

- 时间：本地时区，`YYYY-MM-DD HH:MM`；同日相对时间可用「x 分钟后 / x 小时后」。
- 数值：千分位；百分比一位小数；超过 100% 按 100% 显示进度条，但保留真实数值文案。
- 金额/积分单位沿用平台返回值，不自行换算。
- 空值统一显示 `-`，不显示 `0` 误导用户。

### 4.4 刷新与数据新鲜度

- 自动刷新间隔：60–3600 秒，默认 300 秒。
- 同一时刻只允许一个用量查询在途；新请求在途时跳过。
- 查询失败不写入历史快照，不参与告警判断。
- 手动刷新不受自动刷新间隔限制，但仍受本地 2 秒频控约束。

### 4.5 告警默认阈值（US-01 引用）

- 使用率告警：80%（预警）、95%（严重）、100%（耗尽）。
- 连续登录失败：3 次。
- 以上为默认值，允许在设置页调整；最终默认值 `[待确认]`。

### 4.6 数据保留

- 用量历史默认保留 90 天 `[Assumption, TBD]`，超出后按天滚动清理。
- 告警记录默认保留 30 天 `[Assumption, TBD]`。
- 所有数据仅保存在本机配置目录，不上传。

### 4.7 隐私与安全红线

所有 Story 必须满足：

1. 界面与日志不得展示密码、JWT、完整 API Key。
2. API Key 明文只在用户显式点击「显示 / 复制」时按需获取，用后不写入历史、不进入导出文件。
3. 新增的本地存储数据不得包含凭据。
4. 新增出网请求继续禁用环境代理，并限制在可信域名内。
5. 新增功能不得降低现有 Host / Origin / 会话令牌校验强度。

### 4.8 平台能力不确定性

以下能力依赖 SenseNova 平台是否开放，需在开发前验证；未确认前相关 Story 保持「草案」状态：

| 能力 | 影响 Story |
|---|---|
| API Key 新建 / 禁用 / 删除接口 | US-06 |
| 按模型或按日的消费明细接口 | US-03 的扩展范围 |
| 系统通知在 Windows / macOS 的可用性 | US-01 |
