# US-02 托盘常驻、后台监控与开机自启

---

## 1. 背景与问题

当前应用关闭窗口即退出进程。用量只能在窗口打开时刷新，告警也只能在窗口打开时出现。对一个“监控工具”而言，这等于没有监控。

本 Story 让应用以托盘形式常驻后台（用户可选择关闭即退出），按设定间隔继续查询，并在需要时被用户或系统事件唤起。

---

## 2. 用户故事

> 作为长期使用多个账号的用户，我希望关闭主窗口后应用仍在后台刷新用量，并在托盘上看到当前状态，这样我不需要为了监控而一直开着一个窗口。

**完成条件**：选择「最小化到托盘」后，关闭窗口进程仍在运行，托盘图标可反映状态，重新打开窗口能看到关闭期间的最新数据；默认关闭则正常退出。

---

## 3. 范围

### P0

- 关闭窗口 → 退出应用（默认）；可选「最小化到托盘」继续后台刷新。
- 托盘菜单：打开主窗口、立即刷新、暂停/恢复监控、设置、退出。
- 托盘图标状态：正常 / 告警 / 错误。
- 后台按设置间隔刷新。
- 开机自启开关（用户级，默认关闭）。
- 单实例运行：重复启动唤起已有窗口。
- 首次最小化提示。

### P1

- macOS 菜单栏适配与差异处理。
- 托盘悬浮摘要（账号数、可用数、最近刷新时间）。
- 托盘快捷切换刷新间隔。
- 系统休眠唤醒后自动刷新。

### 不做

- 作为 Windows 服务运行。
- 多用户 / 多会话隔离。
- 托盘内直接展示完整账号表格。

---

## 4. 核心流程

```
启动应用
  → 创建主窗口 + 托盘图标
  → 后台刷新循环开始
  → 用户点关闭
      → 按设置：隐藏到托盘 / 退出
  → 托盘图标持续反映刷新结果与告警状态
  → 点击托盘「打开主窗口」→ 显示窗口并刷新一次
  → 托盘「退出」→ 停止刷新、销毁窗口、退出进程
```

---

## 5. 功能需求

### US02-FR1 关闭窗口行为

**触发**：用户点击自定义标题栏关闭按钮，或使用系统关闭快捷键。

**规则**：

1. 默认行为：退出应用（与系统「关闭即退出」一致），最小化按钮仍走系统最小化。
2. 用户显式选择「最小化到托盘」后，关闭窗口隐藏主窗口，进程继续运行，托盘图标保留。
3. 首次执行隐藏时，显示一次提示：「应用已最小化到托盘，将继续在后台刷新用量。」提供「不再提示」。
4. 用户可在设置页选择关闭行为：
   - 退出应用（默认）
   - 最小化到托盘（后台继续刷新）
5. 选择「退出应用」后，关闭窗口即按 US02-FR5 的退出流程结束进程。
6. 从托盘菜单选择「退出」始终真正退出，不受上述设置影响。

**异常**：托盘创建失败时，关闭行为自动回退为「退出应用」，并提示一次托盘不可用。

### US02-FR2 托盘菜单

| 菜单项 | 行为 |
|---|---|
| 打开主窗口 | 显示并聚焦主窗口；若窗口已显示则聚焦 |
| 立即刷新 | 触发一次用量刷新，结果照常更新托盘状态；刷新中禁用 |
| 暂停监控 / 恢复监控 | 暂停后停止自动刷新与告警；恢复后立即刷新一次 |
| 设置 | 打开主窗口并切换到「系统设置」 |
| 退出 | 停止后台刷新，销毁窗口，退出进程 |

**规则**：

1. 菜单文案随状态变化：暂停后显示「恢复监控」。
2. 无账号时「立即刷新」仍可点击，但结果为空，不报错。
3. 刷新进行中再次点击「立即刷新」不重复发起。

### US02-FR3 托盘图标状态

**状态优先级**：错误 > 告警 > 正常。

| 状态 | 条件 | 图标表现 |
|---|---|---|
| 错误 | 最近一次刷新整体失败，或存在登录失败的账号 | 红色标记 / 红色图标 |
| 告警 | 存在未读告警（US-01）或存在不可用账号 | 橙色标记 |
| 正常 | 刷新成功且无未读告警 | 默认图标 |

**悬浮提示**（P1）：显示「账号 N · 可用 M · 最近刷新 HH:MM」。

**规则**：

1. 托盘状态在每次刷新完成后更新。
2. 暂停监控时图标保持当前状态，悬浮提示标注「监控已暂停」。
3. 状态变化不弹气泡，除非同时满足 US-01 的告警投递条件。

### US02-FR4 后台刷新

**规则**：

1. 窗口隐藏后，自动刷新间隔与设置页一致（60–3600 秒，默认 300 秒）。
2. 窗口可见时由前端驱动刷新；窗口隐藏时由后台驱动刷新。两者不得同时发起请求。
3. 后台刷新只更新数据、告警与托盘状态，不主动弹出窗口。
4. 暂停监控期间不发起任何自动请求；手动打开窗口后仍可手动刷新。
5. 系统休眠 / 锁屏期间不保证刷新；唤醒后若距上次成功刷新超过 60 秒，立即刷新一次 `[Assumption, TBD]`。

### US02-FR5 退出流程

**触发**：托盘菜单「退出」、设置页「退出应用」、系统关机 / 注销。

**规则**：

1. 退出前停止后台刷新循环，避免退出过程中写盘或发请求。
2. 正在进行的刷新允许在 5 秒内完成；超时则不再等待。
3. 退出不得删除配置、历史与告警记录。
4. 系统关机 / 注销时不拦截，按系统流程退出。

### US02-FR6 开机自启

**触发**：用户在设置页开启「开机自动启动」。

**规则**：

1. 默认关闭。
2. 开启后，用户登录系统时自动启动应用，并以隐藏窗口 + 托盘方式运行。
3. 自启启动不弹主窗口、不弹首次最小化提示。
4. 若自启时无任何账号，仍保持托盘运行，不弹提示。
5. 关闭开关后立即移除自启项。
6. 自启失败（权限被拒、注册表/启动项写入失败）时，设置页如实提示失败，开关回到关闭状态。

### US02-FR7 单实例

**触发**：用户再次双击启动应用（快捷方式、开机自启与手动启动同时发生）。

**规则**：

1. 同一用户会话下只允许一个实例。
2. 第二个实例启动时，将已有实例的主窗口显示并聚焦，然后自行退出。
3. 若已有实例处于暂停监控状态，显示窗口不自动恢复监控。
4. 不得因单实例检查失败而阻止首个实例启动。

## 6. 界面与交互

### 设置页新增「运行方式」卡片

```
运行方式
  关闭窗口时          [退出应用 ▾]
  开机自动启动        [关]
  当前状态            后台监控中 / 已暂停
  [暂停监控]
```

- 「关闭窗口时」选项：最小化到托盘 / 退出应用。
- 修改后立即生效并持久化。

### 首次最小化提示

- 一个轻量确认框，文案固定，提供「不再提示」。
- 用户勾选后写入偏好，后续不再出现。

### 托盘

- 左键单击：显示 / 聚焦主窗口。
- 右键：打开菜单。
- 双击行为与左键一致（Windows 习惯）。

## 7. 数据与状态

| 对象 | 字段 | 说明 |
|---|---|---|
| 运行设置 | 关闭行为、开机自启、暂停状态、首次提示已读 | 与现有设置一起持久化；暂停状态建议仅内存态 `[Assumption, TBD]` |
| 托盘状态 | 正常 / 告警 / 错误、最近刷新时间、账号统计 | 内存态，由刷新结果计算 |
| 刷新调度 | 上次刷新时间、下一次计划时间、是否在途 | 内存态 |

**一致性要求**：托盘状态与主窗口展示必须使用同一份最新查询结果，不得各自维护数据副本。

---

## 8. 异常与边界

| 场景 | 行为 |
|---|---|
| 托盘创建失败 | 回退为关闭即退出；设置页隐藏托盘相关选项并提示 |
| 开机自启写入失败 | 开关回退关闭，提示失败原因（脱敏） |
| 后台刷新失败 | 托盘进入错误态；不弹窗；下次按间隔重试 |
| 暂停监控期间用户手动刷新 | 允许，结果只更新界面与托盘，不恢复自动刷新 |
| 窗口隐藏时收到告警 | 由 US-01 发送系统通知；托盘同步变色 |
| 重复启动 | 唤起已有窗口，第二实例退出 |
| 系统注销 / 关机 | 正常退出，不拦截 |

---

## 9. 对现有功能的影响

- **窗口生命周期**：关闭按钮不再直接销毁窗口；需要区分「隐藏」与「退出」。
- **刷新驱动**：当前刷新由前端定时器驱动，需要增加后台驱动并在窗口恢复时同步。
- **设置页**：新增运行方式卡片，设置结构需向后兼容。
- **自动更新**：更新流程需要先退出托盘常驻进程，更新完成后重新启动；更新期间不得有第二个实例争抢。
- **macOS**：托盘 / 菜单栏行为与 Windows 不同，需单独验证。
